# 公共楼道占用巡查与物品处置系统

物业巡查登记公共楼道堆放物品（位置、照片、消防风险级别），向相关楼层住户发
限期清理通知；到期仍在的物品由**两名员工清点、双签封存**，并开放认领期；
期满无人认领的物品**须主管批准**后统一处置。

纯 Python 标准库实现（SQLite + `http.server`，无需安装任何依赖）。

## 启动

```bash
python -m corridor_inspector            # 首次自动播种演示数据并打开浏览器
python -m corridor_inspector --reseed   # 重置演示数据
python -m corridor_inspector --port 8080 --no-browser
```

- 员工端：<http://127.0.0.1:8000/staff>
- 事件页：`/event?id=6`（含**邻居误认**样例）
- 住户端：<http://127.0.0.1:8000/resident>

## 业务流程与分支

```
巡查登记(物品/位置/照片/风险级别/是否易燃/照片是否清晰)
   └─ 通知：有主→私信限期清理；主人不明→公开公告（不含任何个人信息）
        └─ 复查期限届满
             ├─ 易燃/危险品 → 紧急移除（任意阶段，自动报备主管）
             ├─ 住户已自行清走 → 结案（自清回执与封存并发互斥，不重复封存）
             ├─ 照片不清 → 禁止封存，现场重拍清晰照片后解除
             └─ 物品仍在 → 两名不同员工清点 + 双签封存 → 认领公告
                    ├─ 凭非公开特征认领：员工复核，相符发还
                    ├─ 邻居误认（特征不符）→ 判 mistaken，物品继续封存
                    ├─ 封存后损坏 → 登记损坏照片并报备主管
                    └─ 认领期满 → 主管批准后处置（巡查员无权）
```

演示数据覆盖：有主/无主、高/中/低风险、易燃紧急移除、住户自清、照片不清
（禁止封存）、双人封存、邻居误认、凭特征发还、封存后损坏、认领期满待主管
处置。

## 关键规则实现

| 规则 | 实现 |
|---|---|
| 公告不泄露住户信息 | 公告由公共信息（楼层/公共位置/类别/期限）模板生成，姓名/房号/电话不入库公告文本；住户端仅渲染 `kind='public'` 照片 |
| 认领须给非公开特征 | 封存时生成特征密语（`seals.claim_secret`），页面默认隐藏，员工复核时才展开 |
| 并发清理不重复封存 | 物品状态条件更新 + 部分唯一索引 `clear_tickets(item_id) WHERE status='active'`；封存/自清空开 `BEGIN IMMEDIATE` 事务 |
| 双人封存 | `witness1_id != witness2_id` 强校验，双签均落库展示 |
| 处置需主管批准 | `dispose()` 校验角色 `supervisor`、认领期已过、无 matched/pending 认领 |
| 照片不清 | `items.photo_clear=0` 封存抛 `NeedReshootError`，重拍后解除 |

## 界面

浅灰底（`#f0f1f2`）、深绿主色（`#1f5a42`）、消防红仅用于高风险/紧急项
（`#c22020`）。员工端每层一张**楼层平面示意 SVG**，占用点位按风险着色，
待处置紧急项带脉冲圈并在列表中置顶；事件页时间线按 **① 通知 → ② 复查 →
③ 封存/认领/处置** 分区。

## 数据与消息

- SQLite：`data/demo.db`（事件统一存 `events` 表，时间线即事件流）
- 图片：本地 `data/images/`（巡查照片用内置 PNG 绘制器生成占位图）
- 消息：模拟适配器写 `messages` 表，员工端可看"发件箱"（短信/内部报备）

## 测试

```bash
python -m unittest discover -t . -s . -p "test_*.py" -v
```

27 个测试，重点覆盖：

- `test_privacy.py`：公告无姓名/房号/电话；有主通知走私信不入公告；住户端只见公开照片；认领事件隐去联系方式
- `test_concurrency.py`：活动票唯一；自清取消封存票；封存后自清转认领；**两连接屏障并发封存 vs 自清，断言恰好一方成功、封存记录恰好一条**
- `test_seal.py`：同人双签拒绝；双签落库；照片不清禁止封存（重拍解除）；期限未到禁止封存
- `test_disposal.py`：巡查员处置拒绝、主管批准；认领期内主管也不能处置；误认物品继续封存；正确特征发还后不得处置；待复核认领阻断处置；损坏登记；紧急移除仅限易燃物并报备
- `test_web.py`：真实 HTTP 端到端（隐私、置顶、双签 409、处置 303）
